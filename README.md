# 💰 Expense Tracker

A simple and responsive Expense Tracker built with **HTML, CSS, and JavaScript**. It helps users manage their finances by tracking income and expenses, calculating balances automatically, and saving transaction data using Local Storage.

## 🚀 Features

* Add income and expense transactions
* Real-time balance calculation
* Separate income and expense totals
* Transaction history display
* Delete transactions
* Persistent data with Local Storage
* Responsive and clean user interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API

## 📸 Preview

Track your financial activities with an intuitive interface that updates balances instantly as transactions are added or removed.

## ⚙️ How to Use

1. Enter a transaction description.
2. Enter an amount:

   * Positive value = Income
   * Negative value = Expense
3. Click **Add Transaction**.
4. View updated balance, income, expense totals, and transaction history.
5. Delete transactions when needed.
